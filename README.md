# Supermart Grocery Sales Analysis using Excel

## Project Overview
This project focuses on analyzing grocery retail sales data using Microsoft Excel. The objective is to understand sales performance, profitability, discount trends, product category performance, regional sales distribution, and monthly sales patterns through an Excel dashboard.

**Note:** This project uses a synthetic dataset of 500 sample orders created for learning and portfolio purposes. It does not represent actual Supermart company data.

## Project Objectives
- Analyze total sales, profit, and discount trends.
- Identify the best-performing product categories and subcategories.
- Compare sales performance across regions in Tamil Nadu.
- Analyze monthly and yearly sales patterns.
- Identify top-performing cities.
- Compare product category profitability.
- Present key metrics through an Excel dashboard.

## Key Findings
- Bakery is the highest-sales category in the sample dataset.
- West is the highest-sales illustrative region.
- Tiruppur is the top city by sales.
- October is the highest-sales month in the sample.

## Business Recommendations
- Maintain sufficient inventory for high-performing categories.
- Focus on products with higher profit margins.
- Monitor discounts to understand their impact on profitability.
- Compare regional performance to identify growth opportunities.
- Use additional years of real data for year-over-year analysis.
